# opencode-docs

Local reference material for OpenCode V2. Organized by topic — keep new files in a subdirectory, not loose at this level.

## Contents

- `plugin-docs/` — OpenCode V2 plugin API and build docs (plugins, SDK, client, custom tools). Use when building or debugging the `research-chad` plugin.

## Conventions

- One subdirectory per source/topic. Never leave new files loose at this root.
- Filenames should be descriptive: `topic-subject.md`.
- We document the directories under 'Contents' not the files themselves, as the files will frequently change.
- If a topic outgrows its folder or diverges from another, split it into its own reference in `opencode.json`.
